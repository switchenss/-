# GS 双市场实时看盘终端与量化分析工具箱 V1.4.0

作者：Swiftchen

## 项目定位

本项目由实时看盘终端和量化分析工具箱组成，面向 A 股与美股分别接入行情数据，并用统一的 GS 观察、预警、买入观察、风险预警、卖出观察信号展示趋势变化。

## 实时看盘终端

- A 股、美股代码和名称模糊搜索
- A 股、美股分组的自选池
- 自选池新建、重命名、清空、拖拽排序、JSON 导入导出
- 单标的参与模拟开关
- 实时行情轮询，刷新间隔可配置
- 美股 Overnight、Pre-Market、Core、After-Hours 时段识别
- 美东时区与北京时间转换，兼容冬令时
- 仅主盘出信号与全时段模式
- 全时段模式自动提高成交量过滤门槛
- 鼠标滚轮缩放、左键拖动、十字光标
- K 线悬浮卡片，显示 OHLC、ATR、明盘资金、暗盘代理、活跃度和信号说明
- G/GO 与 S/STOP 历史和实时标记
- 明盘、暗盘代理双柱和主力汇总面板
- 紫色、红色、绿色机构活跃度柱及图例
- Windows 弹窗、声音提醒
- SVG 图表和 HTML 策略报告导出

## 虚拟模拟盘

- 本地 USD 虚拟账户
- 历史回测与实时挂机两种模式
- 只有自选池内勾选参与模拟的标的进入实时模拟监控
- G 信号、资金流入、红色或紫色活跃度柱三项共振才允许开仓
- 单标的单笔持仓
- 单笔仓位比例、单日亏损上限、ATR 动态止损均可配置
- 美股只允许限价模拟委托
- 账户净值、可用资金、持仓、浮动盈亏、今日盈亏
- 胜率、最大回撤、盈亏比和交易明细

## 日志与数据

信号、委托、成交、止盈止损和风控拦截写入本地分日 JSONL 日志，并附带行情和指标快照。个人自选、投资方案和运行缓存保留在本地，不上传到公共仓库。

## A 股与美股数据边界

A 股 L2 公式只在通达信 L2 权限和对应字段可用时使用。没有 L2 时采用明确标注的量价代理。美股没有国内逐笔暗盘数据，系统使用 VWAP、OBV、相对成交量、名义金额和背离作为代理，不包装为真实机构资金流。

## 配置与启动

进入 `GS_Workstation` 目录安装 `requirements.txt`，运行 `python dashboard.pyw`。公共仓库提供 `config.public.example.json`，个人配置请复制为本地 `config.json` 后自行填写。

## 风险声明

所有指标仅供技术复盘参考，不构成交易建议。技术信号存在假信号、钝化、数据延迟、流动性变化和黑天鹅失效风险。模拟结果不代表未来收益。
