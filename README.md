# GS 双市场实时看盘终端与量化分析工具箱

V1.4.0 · 作者 Swiftchen

GS 双市场系统是一套面向 A 股和美股的本地化技术分析工作台，提供搜索、自选池、实时分时、GS 信号、资金与活跃度分析、模拟账户和历史回测。

## 主要能力

- A 股和美股代码、名称模糊搜索
- A 股量价代理与授权 L2 数据入口
- 美股主盘、盘前、盘后和隔夜时段过滤
- G/GO 与 S/STOP 趋势信号
- 明盘资金、暗盘代理、主力汇总和机构活跃度
- 可拖拽自选池与参与模拟白名单
- 实时分时刷新和 Windows 弹窗、声音提醒
- USD 100,000 本地虚拟账户
- 15% 单笔仓位上限、3% 日亏损限制和 ATR 动态止损
- 限价模拟撮合、历史回测、账户绩效和分日日志
- SVG 图表、HTML 策略报告和完整测试模块

## 快速启动

进入 GS_Workstation 目录，使用 Python 3.11 或更新版本。

    python -m pip install -r requirements.txt
    python dashboard.pyw

也可以双击 Windows 桌面的「GS 双市场分析工作台」。

顶部选择「实时看盘」后，系统按配置刷新分时行情。默认每 60 秒，可在「模拟设置」中调整到 15 秒。只有自选池中勾选「参与模拟」的标的进入实时模拟和后台预警。
